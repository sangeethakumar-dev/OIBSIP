# Iris Flower Classification

## Oasis Infobyte Data Science Internship - Task 1

This project was developed as part of the **Oasis Infobyte Data Science Internship Program (OIBSIP)**.

The objective of this project is to build a machine learning classification model that predicts the species of an Iris flower based on its sepal and petal measurements.

## Objective

The goal is to classify Iris flowers into one of three species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

The classification is performed using four numerical features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Dataset

The project uses the **Iris dataset** available directly through Scikit-learn.

The dataset contains 150 samples belonging to three Iris species.

No external dataset download is required for this project.

## Project Workflow

The project follows these major steps:

1. Import required libraries
2. Load the Iris dataset
3. Understand the dataset structure
4. Perform Exploratory Data Analysis (EDA)
5. Visualize feature distributions and relationships
6. Analyze feature importance and discriminative features
7. Prepare features and target variables
8. Split the dataset into training and testing sets
9. Train multiple classification models
10. Evaluate the models
11. Compare model performance
12. Select the best-performing model
13. Draw final conclusions

## Machine Learning Models
