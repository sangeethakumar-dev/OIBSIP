# OIBSIP - Oasis Infobyte Data Science Internship

This repository contains the projects completed as part of the **Oasis Infobyte Data Science Internship Program (OIBSIP)**.

The internship focuses on applying Python, Data Science, Machine Learning and Natural Language Processing techniques to real-world datasets.

## Track

**Data Science**

## Projects

### Task 1 - Iris Flower Classification
Build a machine learning classification model to predict the species of an Iris flower based on its physical measurements.

**Key Concepts:** Exploratory Data Analysis, Data Visualization, Classification, Model Evaluation

### Task 3 - Car Price Prediction with Machine Learning
Build regression models to predict the selling price of used cars using features such as brand, age, mileage, fuel type and transmission.

**Key Concepts:** Data Cleaning, Feature Engineering, Regression, Feature Importance, Model Evaluation

### Task 4 - Email Spam Detection with Machine Learning
Build an NLP-based machine learning classifier to distinguish spam messages from legitimate messages.

**Key Concepts:** NLP, Text Preprocessing, TF-IDF, Classification, Model Evaluation
